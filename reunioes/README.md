# reunioes/

Atas e desdobramentos de reuniões com clientes do escritório.

## Padrão de nomes
- `AAAA-MM-DD_ata_<cliente>.md` — ata completa, com linha do tempo, decisões e checklist.
- `AAAA-MM-DD_mensagem_grupo_<assunto>.md` — texto pronto para colar no grupo do cliente.
- `AAAA-MM-DD_minuta_<peca>_<parte>.md` — minutas de notificações, contratos e afins.

## Regras
- Nunca inventar dados que não estejam na reunião. O que é inferência do escritório
  vem marcado como **[análise do escritório]**.
- Timestamps entre parênteses remetem ao minuto da gravação.
- Checklists usam `- [ ]` / `- [x]` e devem ser atualizados no próprio arquivo.
